# Приглашение

Статический мобильный сайт без установки зависимостей. Все изображения локальные; исходный макет сохранён без изменений. Текст и зелёные кнопки остаются частью изображения, а доступные интерактивные области расположены поверх них.

## Локальный запуск

Из `/workspace/mane` запустите `python3 -m http.server 8080 --bind 0.0.0.0`. Откройте корень сервера. Для размещения подойдёт любой HTTPS-хостинг статических сайтов: публикуйте `index.html`, `styles.css`, `app.js` и папку `assets`.

## Подарок и музыка

В начале `app.js` задайте `CONFIG.certificateImage` (путь к картинке сертификата) и/или `CONFIG.certificateUrl` (ссылка на PDF или страницу сертификата). Пока они пусты, окно честно сообщает, что сертификат не добавлен.

Для выбранной композиции добавьте аудиофайл в `assets` и задайте `CONFIG.musicUrl`, например `assets/music.mp3`. Пока URL пуст, браузер генерирует тихую временную мелодию. Звук начинается после нажатия на печать; выключатель расположен справа сверху. При скрытии вкладки музыка приостанавливается.

QR-код должен вести на окончательный публичный HTTPS-адрес сайта. Адрес хостинга и сам сертификат пока не предоставлены; публикация и создание окончательного QR-кода не выполнены.

## Проверки

Проверьте открытие печати, шесть экранов, переход назад, выключение и включение музыки, открытие и закрытие сертификата. Доступны клавиатура и режим уменьшенной анимации. На реальном iPhone/Android нужно дополнительно проверить воспроизведение выбранного аудиофайла после его добавления.
