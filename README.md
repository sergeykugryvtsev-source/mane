# Приглашение

Статический мобильный сайт без установки зависимостей. Каждый экран использует отдельный портретный PNG примерно 850 × 1845 пикселей (`assets/screen-1-hd.png` — `assets/screen-6-hd.png`). Это самостоятельные фоны, воссозданные по утверждённой композиции. Старый общий макет `assets/invitation.png` сохранён как исходный референс и больше не используется для отображения сайта.

Весь текст, счётчики, иконки и кнопки находятся в HTML/CSS: они остаются чёткими на Retina-экранах и редактируются в `index.html` без изменения фотографий. Первый фон загружается в приоритете, остальные подгружаются последовательно. Изображения не растягиваются из маленьких фрагментов общей картинки.

## Локальный запуск

Из `/workspace/mane` запустите `python3 -m http.server 8080 --bind 0.0.0.0`. Откройте корень сервера. Для размещения подойдёт любой HTTPS-хостинг статических сайтов: публикуйте `index.html`, `styles.css`, `app.js` и папку `assets`.

## Страницы «Оставить на потом»

Кнопка на шестом экране открывает отдельную ветку из двух страниц с теми же четырёхсекундными переходами. Первая использует кремовую бумагу с оливковыми ветвями: вверху «Всему своё время», по центру справка о глицирризиновой кислоте в корне солодки, ниже «Сертификат действует год» и «Есть время выбрать свой день». Вторая использует фон заката: «Когда передумаешь — возвращайся», кнопки возврата на шестой экран приглашения и просмотра сертификата. Тексты редактируются в `index.html`; реальная дата окончания сертификата пока не задана. Основные шесть экранов сохраняют свою нумерацию, у дополнительной ветки отдельный счётчик 1/2 и 2/2.

В `CONFIG.laterMusicUrl` подключена предоставленная пользователем вторая композиция: `assets/later-song-soft.mp3`. Для неё подготовлена тихая версия со снижением уровня на 18 дБ и плавным вступлением на 3 секунды. Используется один постоянный HTML-аудиоплеер: при переходе меняется его источник, что сохраняет разрешение воспроизведения, полученное первым нажатием, в мобильных браузерах. Устаревшие отклонённые запросы play() не выключают уже выбранную новую песню. При нажатии «Оставить на потом» дорожка переключается внутри события нажатия; на двух дополнительных страницах звучит вторая песня, при возвращении возобновляется «Маяки». Явное выключение звука сохраняется, позиции дорожек сохраняются и восстанавливаются при поддержке HTTP Range на хостинге; две композиции одновременно не играют. Проверено воспроизведение именно предоставленного второго трека, его длительность около 173 секунд, переключение, возврат, продолжение на второй дополнительной странице и поведение при выключенном звуке.

## Подарок и музыка

В начале `app.js` задайте `CONFIG.certificateImage` (путь к картинке сертификата), `CONFIG.certificateUrl` (ссылка для просмотра) и `CONFIG.certificateFile` (прямой путь к скачиваемому PDF или изображению). Для GitHub Pages предпочтителен файл в `assets`, на том же домене: тогда работает атрибут `download`. Кнопка скачивания отключена, если путь к файлу пуст. Сейчас для проверки подключён тестовый PDF. После получения настоящего сертификата замените путь в `certificateFile` и установите `certificateIsTest: false`. Для изображения или PDF в `certificateUrl` предусмотрен автоматический выбор файла, но отдельный путь `certificateFile` надёжнее. На iPhone браузер также может предложить сохранить файл через меню «Поделиться» → «Сохранить в Файлы».

В `CONFIG.downloadNotificationEndpoint` подключена предоставленная пользователем форма `https://formspree.io/f/mjyglneq` для уведомлений на Яндекс Почту. Получатель и подтверждение почты настраиваются в Formspree; пароли и приватные API-ключи в сайт добавлять нельзя. Для замены получателя измените настройки формы в Formspree. Реальный сертификат ещё не предоставлен. Временно подключён `assets/test-certificate.pdf`, явно помеченный «Не является подарочным сертификатом», и установлен `CONFIG.certificateIsTest: true`. Кнопка скачивания активна; тестовые уведомления помечаются `[ТЕСТ]`. В тестовом режиме окно показывает, приняла ли форма запрос или вернула ошибку. Доставка настоящего письма пока не проверена: исходящие запросы к Formspree из облачной машины блокируются сетевой политикой, проверка с сайта в обычном браузере выполняется пользователем. Если URL формы очистить, уведомления отправляться не будут.

Сервис получает событие `certificate_download_requested` только при нажатии «Скачать» — не при открытии окна. Подтверждение сохранения файла на телефоне недоступно браузеру. При включённых уведомлениях под кнопкой показано короткое предупреждение для получателя подарка. Ошибка почтового сервиса не блокирует скачивание; повторное нажатие временно блокируется на 1,5 секунды. В браузерной проверке тестовый PDF действительно скачан, содержимое и имя проверены; запрос к почтовому сервису перехвачен тестом, настоящее письмо не отправлялось.

Подключена предоставленная пользователем композиция IOWA — «Маяки». Оригинал сохранён без изменений в `assets/iowa-mayaki.mp3`. Сайт использует отдельную тихую версию `assets/iowa-mayaki-soft.mp3`: уровень самого аудиосигнала снижен на 18 дБ, в первые три секунды добавлено плавное нарастание. Это работает и в iOS-браузерах, где программное значение `audio.volume` может игнорироваться. Абсолютная слышимая громкость по-прежнему зависит от телефона, наушников и системных настроек.

Звук начинается после нажатия на печать; выключатель расположен справа сверху. При скрытии вкладки музыка приостанавливается. Для замены композиции измените `CONFIG.musicUrl`; для нового файла также подготовьте тихую версию, например `ffmpeg -i original.mp3 -map 0:a:0 -vn -map_metadata -1 -af 'volume=-18dB,afade=t=in:st=0:d=3' -c:a libmp3lame -b:a 320k quiet.mp3`. Если URL пуст, используется временная мелодия Web Audio.

GitHub Pages настроен пользователем на ветку `main`, папку `/ (root)`. Адрес сайта: https://sergeykugryvtsev-source.github.io/mane/. QR-код должен вести на этот адрес. Сам сертификат пока не предоставлен.

## Проверки

Каждый переход длится около 4 секунд, из которых 2 секунды занимает проявление следующего экрана. При открытии конверта поднимаются два полупрозрачных слоя фотографического дыма (`assets/fireplace-smoke.png`); на остальных переходах вперёд и назад проходит мягкая световая вуаль. Сами фотографии не двигаются, не деформируются и не размываются. Следующий фон декодируется до запуска эффекта, повторные нажатия блокируются до его завершения, выключатель музыки остаётся доступным. Если декоративный PNG дыма не загрузился, используется световой переход. При включённом уменьшении движения сохраняется двухсекундное проявление и спокойное свечение, но дым и движущаяся световая полоса отключены. Проверены все переходы вперёд, возврат назад, реальное время анимаций, работа эффектов и их полное удаление после перехода, музыка, окно сертификата, режим уменьшенного движения и резервный эффект при недоступном PNG.

Проверены в Chromium размеры 390 × 844, 375 × 667 и 430 × 932 с deviceScaleFactor 3: загрузка шести отдельных HD-изображений, размещение текста в пределах экрана, открытие печати, шесть экранов, переход назад, выключение и включение музыки, открытие и закрытие сертификата, кнопка «Оставить на потом». Ошибок JavaScript нет. Доступны клавиатура и режим уменьшенной анимации. На реальном iPhone/Android нужно дополнительно проверить воспроизведение выбранного аудиофайла после его добавления.
